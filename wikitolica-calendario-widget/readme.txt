Muestra el santoral, las fiestas litúrgicas y los tiempos del año litúrgico directamente desde la Enciclopedia Católica Wikitólica. Fácil de usar como bloque Gutenberg, widget clásico o shortcode.

== Descripción ==

El **Widget Calendario de Wikitólica** te permite mostrar de forma automática y actualizada el santoral católico, las fiestas y solemnidades, y los tiempos litúrgicos (Adviento, Navidad, Cuaresma, Pascua, Tiempo Ordinario, etc.) en tu sitio WordPress.

Es 100% gratuito, no requiere API ni registro, totalmente responsive y se actualiza directamente desde la fuente oficial de Wikitólica.

**Características principales:**

* Bloque Gutenberg nativo
* Widget clásico (compatible con temas tradicionales)
* Shortcode para máxima flexibilidad
* Elige cuántos días mostrar (de 1 a 360)
* Diseño limpio y responsive
* Sin ralentizar tu web (script cargado con defer)
* Enlace de atribución a Wikitólica (obligatorio)

== Instalación ==

1. Sube la carpeta `wikitolica-calendario-widget` a la carpeta `/wp-content/plugins/`
2. Activa el plugin en **Plugins > Instalados**
3. ¡Listo!

**Cómo usarlo:**

**Como Bloque Gutenberg:**
- Edita una página o entrada
- Busca “Calendario Wikitólica”
- Añádelo y configura el número de días en la barra lateral (o edita como HTML)

**Como Widget Clásico:**
- Ve a **Apariencia > Widgets**
- Arrastra el widget “Calendario Wikitólica” a la zona deseada
- Configura los días a mostrar

**Con Shortcode:**
[wikitolica_calendario days="14"]
Puedes cambiar `14` por cualquier número entre 1 y 360.

== Preguntas frecuentes ==

= ¿Necesito registrarme o tener una API key? =
No. El widget es completamente gratuito y funciona sin ninguna clave.

= ¿Cuántos días puedo mostrar? =
Desde 1 hasta 360 días.

= ¿Funciona en WordPress.com? =
Sí, siempre que tengas un plan que permita instalar plugins.

= ¿El widget se actualiza automáticamente? =
Sí. Los datos siempre se obtienen directamente de Wikitólica.
